# Central de Alertas Fadiga

Sistema de acompanhamento das ocorrências do sistema fadiga.

Fluxo: o operador registra a ocorrência → o gestor do setor aplica a medida → o RH finaliza.

- Site: https://joaovitor-crv.github.io/alertas-fadiga
- Banco de dados e login: Supabase (as informações ficam no banco, protegidas por usuário e senha; este repositório contém apenas a página).
